# 当前项目 Logo

本目录保存项目负责人明确要求提交到开发仓的现用 Logo，便于协作者获取与核对素材。这些文件按原样复制，不包含此前未采用的设计概念稿。

| 文件 | 用途 |
| --- | --- |
| [logo.svg](logo.svg) | 浅色界面使用的主 Logo：深蓝底、白色菱形与中心圆点 |
| [logo-dark.svg](logo-dark.svg) | 深色界面使用的反色 Logo，几何与主 Logo 一致 |
| [app-icon.png](app-icon.png) | 当前客户端使用的应用图标 |

![当前 Logo](logo.svg)

这里只公开三份图形素材，不包含渠道配置、产品标识、服务端地址、登录资料或密钥。`brands/official/` 仍保留官方构建使用的素材。

此目录不会自动改变构建渠道。需要按项目品牌打包时，应按负责人提供的私有配置，将本目录素材同步到对应的本地渠道素材目录，再按根 [README](../../README.md#客户端打包与品牌) 执行构建。通用功能开发可以使用官方渠道与本机测试服务端。

后续若批准修改现用图形，应先更新本目录的素材，再同步本地渠道副本；不要手改 `packages/host/desktop/build/` 中的派生产物。
